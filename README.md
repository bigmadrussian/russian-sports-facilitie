# Regional Sport Analysis 🇷🇺

Анализ объектов спорта по регионам России. Учебный проект на Java: парсинг CSV, загрузка в PostgreSQL, агрегации, визуализация через JFreeChart.

## 📌 Цели проекта

1. Загрузить и распарсить CSV-файл с информацией об объектах спорта.
2. Преобразовать и сохранить данные в БД PostgreSQL, соблюдая 3НФ.
3. Выполнить SQL-анализ:
   - Построить гистограмму объектов по регионам (с объединением "Москва" и "Московская область").
   - Рассчитать среднее количество объектов спорта по регионам.
   - Определить топ-3 регионов по числу объектов.
4. Визуализировать данные и сохранить результаты в PNG-графиках.
5. Задокументировать проект и выложить в открытый репозиторий.

## 🛠 Технологии

- Java 17
- JDK + Maven
- PostgreSQL
- JDBC
- JFreeChart
- OpenCSV (встроенный парсинг)
- UTF-8 и CP1251 поддержка
- Git, GitHub
